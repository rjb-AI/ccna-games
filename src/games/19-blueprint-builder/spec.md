# Blueprint Builder

Topics: v2-1.2 (hypervisors, VMs and containers). v2.0 shrinks this game to these three
subjects (plan section 6).

| Level          | Mode  | What's generated                             | Pass | Time  |
| -------------- | ----- | -------------------------------------------- | ---- | ----- |
| `vm-container` | Learn | Facts → VM, container or both                | 60%  | –     |
| `hypervisors`  | Learn | Products and descriptions → type 1 or type 2 | 60%  | –     |
| `briefs`       | Learn | A client brief → best platform               | 60%  | –     |
| `quick-fire`   | Drill | Mix                                          | 70%  | 150 s |

Correctness source: fixed fact tables in `generator.ts`, sourced from NIST SP 800-125 and
SP 800-190. Tests: `generator.test.ts`.
